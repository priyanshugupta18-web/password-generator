# Password Generator

## Description
This is a simple password generator built with HTML, CSS and JavaScript for the purpose of learning and practicing JavaScript logics and problem solving.

## Technologies Used
- HTML
- css
- JavaScript
- git (version-control)
- mdn documentation (for technical refernces)

## Tools Used
- VS code
- GitHub
- vercel (for web-hosting services and domain)

## How to use
Simply enter the length of password into the character count section, then enter the count of numbers in the number count section and then enter count of special characters in special character count section, finally click on the generate button, you will see that a password is generated for you in result field now, just copy it by clicking on the copy button and use wherever you want.

you can generate as many passwords as you want, simply click in the generate button and everytime you will get a new password when you click on the generate button.

## Tech Logic
used HTML form for the user-input, created three function for generating alphabets, numbers and special characters randomly and then created a function which display the final pasword after concatenating alphabets, numbers and special characters and then randomly shuffling them.
